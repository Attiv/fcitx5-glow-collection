# Glow Collection · 小企鹅 macOS 发光主题

**14 套独立主题，28 组深浅配色。** 默认横排；所有主题均为当前选中的候选提供光晕。仅使用本地 CSS，无远程素材、字体下载或 JavaScript 插件。

## 使用方法

1. 将 `Glow-*.conf` 放入 `~/.local/share/fcitx5/theme/`
2. 将对应 CSS 放入 `~/.local/share/fcitx5/www/css/`
3. 打开小企鹅 **主题编辑器 → 基础 → 选择/导入主题**，选择 `Glow-*.conf`
4. 检查 **高级 → 用户 CSS** 是否指向对应 `glow-xxx.css`

详见 [完整说明](README-Glow.md)。

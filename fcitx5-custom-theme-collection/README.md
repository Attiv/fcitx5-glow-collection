# Fcitx5 自定义主题合集

这是一个面向 Fcitx5 macOS Webpanel 的候选窗主题包，共 71 套主题。

## 特色

- 所有主题均为纵排候选布局
- 隐藏候选窗左侧翻页按钮
- 15px 常规字重，紧凑间距与较小高亮圆角
- 每套主题均有适合其风格的低对比度静态背景
- 同时适配亮色与暗色模式
- 不包含网络资源、JavaScript 插件或 Glow 主题

主题涵盖多巴胺、极简主义、日式和风、黑色电影、孟菲斯、包豪斯、马卡龙、莫兰迪、蒸汽波、合成波、赛博朋克、Y2K、哥特式、暗黑学院、装饰艺术、蒸汽朋克、北欧、侘寂、新中式和热带主义等风格。

## 一键安装

打开“终端”，进入解压后的目录并执行：

```sh
chmod +x install.sh
./install.sh
```

安装完成后，在 Fcitx5 设置中选择需要使用的用户主题。如果主题列表没有立即刷新，请退出并重新启动 Fcitx5。

## 手动安装

将以下目录中的文件复制到对应位置：

- `theme/*.conf` → `~/.local/share/fcitx5/theme/`
- `www/css/*.css` → `~/.local/share/fcitx5/www/css/`

同名文件会被替换，其他主题不会被删除。

- 主题配置：71 个
